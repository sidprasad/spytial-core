Toolbar & sizing

What changed: one style for every toolbar button (so an injected button looks native), a Fit to View glyph that does not look like full screen, and CSS-only sizing.

Walkthrough

  1. Sized by one CSS rule webcola-cnd-graph { width: 100%; height: 480px; }. Drag to change the height; the diagram is re-fit after each change with resetViewToFitContent().
  2. Attributes are not read Press this to set width="300" height="200" on the tag. The measured box does not move.
  3. Fit to View is ⧈ A square inside a square: the content framed by the view. The old ⤢ read as "full screen".
  4. Full screen, injected in 3 lines The ⛶ button at the right of the toolbar is not built in. It is a bare <button> passed to addToolbarControl(), and it picks up the toolbar's style with no class. Click it. Esc leaves.
