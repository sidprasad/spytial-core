# spytial-core

> A browser-side engine for turning relational data plus a spatial spec into a diagram.

This guide is for **developers integrating Spytial into their own language or tool**.

To use Spytial with Python, Rust, Pyret, Lean, Alloy, Forge, or graph descriptions, see [Integrations](integrations.md) for browser demos, VS Code extensions, installation instructions, and docs. If you are wiring Spytial into another host (a language, editor, notebook, debugger, or proof assistant), start here.

Start with [What is spytial-core?](getting-started.md), then read [New Language Integration](new-language-integration.md).
